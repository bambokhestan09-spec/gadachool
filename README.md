# گداچول — لیگ گداهای استرسی ۲

این نسخه یک PWA موبایل‌محور است.
- پیش‌بینی داخل سایت انجام نمی‌شود.
- کاربر فقط بازی‌های بعدی را می‌بیند و برای پیش‌بینی به فوت‌موب می‌رود.
- جدول فعلی اعضا در طراحی اولیه وارد شده است.
- برای آنلاین شدن، کل این پوشه را روی هر هاست HTTPS قرار دهید و `index.html` را به‌عنوان صفحه اصلی سرو کنید.
